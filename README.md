## 打开方式

纯静态站，无构建步骤、无依赖：

```bash
cd site && python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

直接双击 `site/index.html` 用 `file://` 打开也可以（脚本用的是普通 `<script src>`，不走 fetch，不受 CORS 限制）。

## 三处勘误（照原文做会踩坑）

1. **FreeCAD 版本** —— 原文说 1.1 落地于 2026-03 属实，但现已迭代到 **1.1.3**，别照抄 1.1.0。
2. **PyBullet 停更理由** —— 原文说「2022 后无新版本、issue 区已关」不成立。PyPI 上 3.2.7 发布于 2025-01-30，issue 区开放且有 430 个未关闭条目。结论（新人不必投资）不变，理由要换。
3. **美国官方薪资口径** —— 122,930 美元这个数字在 O*NET 上确实存在，但标注来源是「Engineers, All Other」兜底大类，**并不统计机器人工程师这个职业**。

## 国内落地信息（原文没有、中文核查补充的）

- SO-101 官方物料清单自带淘宝价：主从一对 **1343.16 元**、单条从臂 **682.23 元**
- 关键发现：省的不是核心件。STS3215 舵机在中/美/欧三地几乎同价（97.7 / 98.6 / 101.3 元），日本贵 45%；国内的优势在周围杂件的供应链密度（六颗舵机占单臂总价国内 86%、美国 68%）
- 工具台预算四档的国内价格区间、采购渠道反转建议（原文的「等 2–6 周海运」对国内反过来）
- ROS 2 版本表、Gazebo 配对表
- IFR World Robotics 2026 中国装机数据

## 核验状态（2026-09-30 本机实测）

站内每条资源都带核验徽章，可在资源库按「核验」维度筛选。**17 条未独立核验，占位待人工补齐。**

| 类别 | 条数 | 含义 | 处理 |
|---|---|---|---|
| 已亲自打开验证 | 106 | curl + 浏览器返回 200 | — |
| 反爬未打开 | 12 | 站点有人机验证返回 403；**主机在线但内容我没读到** | 徽章 + 清单列出 |
| 网络受限未验证 | 4 | 本机 DNS 全部解析到 `172.19.x.x` 私有段，出网被拦，curl 与浏览器均失败 | 徽章 + 清单列出 |
| 原文自述未核验 | 1 | 英文原文自己标注「未核验」 | 徽章 + 原文原话转述 |

未核验条目的**说明与价格全部是两篇原文的转述，没有为它们编造任何补充内容**。等通过验证后，按站内「核验」板块的清单逐条回填（当前页数、价格、课程目录、是否仍免费）。

另外站内区分了**来源可信度四档**（A 官方一手 / B 折算推导 / C 中文作者估算 / D 仅转述未核验），避免「数字看起来像真的」和「数字能追溯到官方口径」被混为一谈。

## 验证记录

- 条目数对账闭合：按月求和 = 按类型求和 = 按核验状态求和 = 123
- 116/116 原文链接全部落库，零遗漏
- 零控制台报错，HTML 标签闭合校验通过，5 个文件均无控制字符与非法 Unicode
- 搜索 / 月份筛选 / 类型筛选 / 核验状态筛选 / 组合筛选 / 打卡 localStorage 持久化均实测通过
- 已修的真实 bug：两处 HTML id 重复（`#errata`、`#projects`）导致脚本清空整个 section；类型分类字段未从 section 传递导致类型筛选返回 0；Glassdoor 题库未纳入资源库；ESP32 克隆板名称不匹配导致徽章失效

## 部署
